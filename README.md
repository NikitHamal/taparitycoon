# Momo & Chiya Empire (Tapari Tycoon)

A funny 3D low-poly idle arcade tycoon for Android, written in Kotlin with an OpenGL ES 3.0 renderer and a Jetpack Compose HUD.

Start with a thela in Baneshwor, haul maida and meat to the giant steaming Moktu, serve towers of momo plates, refill the Extra Jhol cauldron before customers flip out, deal with Chiya & Churot campers, hire your crew and grow into a Kathmandu momo empire.

Package: `com.tapari.tycoon`. Builds are produced by GitHub Actions - grab the APK from the **latest Release**.
